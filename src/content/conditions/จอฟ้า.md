## จอฟ้า (Blue Screen) คืออะไร

Windows หยุดทำงานแล้วขึ้นหน้าจอสีฟ้ามีรหัสผิดพลาด อาจรีสตาร์ทเองหรือค้างให้กดรีเซ็ต — บางทีเกิดตอนเปิดเครื่อง บางทีตอนเสียบอุปกรณ์หรือเล่นเกม

## รับซื้อได้ไหม

รับประเมินได้ครับ โดยร้านจะดูความถี่ รหัสที่ขึ้น และสภาพฮาร์ดแวร์ร่วม ไม่สรุปทันทีว่าบอร์ดพังทุกเคส เพราะจอฟ้ามีได้ทั้งไดรเวอร์ แรม SSD หรือความร้อน

## ปัจจัยราคาเฉพาะจอฟ้า

- ขึ้นทันทีตอนเปิด หรือต้องใช้งานหนักก่อน
- มี Stop code ให้เห็นซ้ำ ๆ หรือสุ่มหลายรหัส
- แรมเพิ่งเพิ่มเอง / SSD ใหม่ใส่มาคู่อาการไหม
- เคยมี [บูตวน](/รับซื้อโน๊ตบุ๊ค/บูตวน/) หรือดิสก์เตือนก่อนหน้า

ตัวอย่างจำลอง: โน้ตบุ๊คทำงานจอฟ้าตอนเปิด Chrome หลังอัปเดตไดรเวอร์ จอและบอดี้ดี — กรอบราคาอาจใกล้เครื่องตรวจซอฟต์แวร์/แรม มากกว่าเคสเปิดไม่ติด

## ส่งอะไร

1. รูปหน้าจอฟ้าให้เห็นตัวอักษรรหัส
2. วิดีโอช่วงก่อนจอฟ้าถ้าจับได้
3. รายการอัปเกรดที่เคยทำ
4. สเปกเครื่อง

## ก่อนขาย

- จดรหัส Stop code ไว้ในแชท
- สำรองไฟล์ถ้าระบบยังเข้าได้เป็นพัก ๆ
- ถอดแรมที่เพิ่งเพิ่มออกทดลองได้ถ้าชำนาญ แล้วบอกผล
