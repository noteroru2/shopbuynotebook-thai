**SSD เสียขายได้ไหม** — ขายได้ครับ โดยเฉพาะถ้าตัวเครื่องส่วนอื่นยังดี ร้านรับซื้อมักประเมินจากรุ่น สเปกหลัก และต้นทุนเปลี่ยนไดรฟ์ ไม่ได้ตัดทิ้งแค่เพราะไดรฟ์เสีย

## SSD เสียคืออะไร

อาการที่คนมักเรียกว่า SSD เสีย ได้แก่

- เปิดเครื่องแล้วค้างโลโก้ หรือบูตวน
- Windows มองไม่เห็นไดรฟ์ / ขึ้น No Boot Device
- ไฟล์หายหรือคัดลอกไม่ได้บ่อย
- เครื่องเปิดติดบ้างไม่ติดบ้างหลังอัปเดตหรือตกกระแทก

อาการเหล่านี้ไม่เสมอไปว่าเป็นบอร์ดเสีย บางเคสจำกัดอยู่ที่ไดรฟ์อย่างเดียว

## ทำไมถึงกระทบการขาย

SSD เป็นชิ้นส่วนที่เปลี่ยนได้ในหลายรุ่น แต่ยังมีผลกับราคาเพราะ

1. ผู้ซื้อมือสองต้องเผื่อค่าไดรฟ์ใหม่
2. บางรุ่นถอดยากหรือใช้ SSD แบบ onboard
3. ถ้ายังอ่านข้อมูลไม่ได้ ต้องเผื่อเวลาตรวจเพิ่ม

อ่านหน้าอาการตรง: [รับซื้อโน๊ตบุ๊ค SSD เสีย](/รับซื้อโน๊ตบุ๊ค/ssd-เสีย/)

## เช็กเบื้องต้นอย่างไรก่อนส่งประเมิน

ถ้ายังเปิดเข้า BIOS หรือระบบได้

- ดูว่ามีไดรฟ์โชว์ใน BIOS / Disk Management หรือไม่
- บอกว่าเคยลองถอดใส่ใหม่หรือเปลี่ยนไดรฟ์แล้วหรือยัง
- ถ่ายวิดีโอตอนกดเปิดให้เห็นอาการบูต

ถ้าเข้าไม่ได้เลย ส่งรูปใต้เครื่อง + วิดีโออาการก็พอ ไม่ต้องฝืนซ่อมเองก่อน

## ความหมายต่อการรับซื้อ

- ไดรฟ์เสียแต่บอร์ด/จอ/พอร์ตดี: มักยังมีมูลค่าตามรุ่น
- บูตร่วมกับอาการอื่น เช่น จอฟ้าหรือรีสตาร์ทเอง: อาจต้องประเมินความเสี่ยงกว้างขึ้น
- เครื่องเกมมิ่งหรือสเปกสูง: แม้ SSD เสียก็ยังมีคนสนใจถ้า GPU/CPU ยังดี

## ส่งอะไรให้ประเมินได้ไว

1. รุ่นเครื่องหรือรูปสติ๊กเกอร์ใต้เครื่อง
2. สเปก CPU/RAM/SSD เดิมถ้าทราบ
3. วิดีโออาการ 5–10 วินาที
4. แจ้งชัด: มองไม่เห็นไดรฟ์ / บูตวน / เข้า Windows ไม่ได้
5. มีที่ชาร์จไหม
