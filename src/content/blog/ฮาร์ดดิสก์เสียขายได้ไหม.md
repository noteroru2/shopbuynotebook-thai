**ฮาร์ดดิสก์เสียขายได้ไหม** — ขายได้ครับ โดยเฉพาะโน๊ตบุ๊คที่ยังใช้ HDD เป็นไดรฟ์หลัก ร้านมักมองมูลค่าจากรุ่นและสเปก CPU/RAM แล้วเผื่อต้นทุนเปลี่ยนเป็น SSD มากกว่าตัดทิ้งเครื่องทั้งเครื่อง

## ฮาร์ดดิสก์เสียหน้าตาเป็นอย่างไร

- เปิดเครื่องช้ามากหรือค้างที่โลโก้นาน
- มีเสียงแปลกจากไดรฟ์ (ติ๊ก/คลิก) แล้วตามด้วยบูตไม่ขึ้น
- Windows ขึ้นเช็กดิสก์บ่อย หรือไฟล์เสียบ่อย
- Disk Management มองไม่เห็นไดรฟ์ หรือขึ้น Unknown

บางคนสับสนกับ SSD เสีย ถ้าคุณไม่แน่ใจว่าเป็น HDD หรือ SSD ให้ส่งรูปสเปกหรือหน้า Storage มาได้

## ทำไมยังมีราคา

HDD มือสองแทบไม่เพิ่มมูลค่าอยู่แล้ว การเสียจึงมักกระทบราคาในมุม “ต้องเปลี่ยนไดรฟ์” ไม่ใช่ “เครื่องใช้ไม่ได้ทั้งเครื่อง” โดยเฉพาะถ้า

- CPU และ RAM ยังใช้งานงานเอกสารได้
- ตัวเครื่องและจอสวย
- พอร์ตกับแบตใช้งานได้

## เช็กง่าย ๆ ก่อนขาย

1. ฟังเสียงไดรฟ์ตอนเปิดเครื่อง
2. ดูใน BIOS ว่ามี Hard Disk/HDD โชว์ไหม
3. ถ้าเข้า Windows ได้ ให้ดู Device Manager / Disk Management
4. บอกว่ารุ่นเครื่องรองรับการอัปเป็น SSD ได้หรือไม่ ถ้าเคยรู้มาก่อน

## ความหมายต่อราคารับซื้อ

- HDD เสียอย่างเดียว: มักหักตามต้นทุนไดรฟ์และค่าเวลา
- HDD เสีย + เครื่องร้อน/ค้างบ่อย: อาจต้องเช็กเพิ่ม
- เครื่องเก่ามากแต่ยังเปิดบอร์ดได้: ยังประเมินได้ตามสภาพจริง

อ่านเทียบไดรฟ์: [ฮาร์ดดิสก์กับ SSD ผลต่อราคารับซื้อโน๊ตบุ๊คมือสอง](/blog/ฮาร์ดดิสก์กับ-ssd-ผลต่อราคารับซื้อโน๊ตบุ๊คมือสอง/)

## ส่งอะไรบ้าง

- รูปรอบเครื่อง 3–5 รูป
- รูปใต้เครื่องหรือรุ่น
- วิดีโออาการบูตหรือเสียงแปลก
- สเปก CPU/RAM
- มีที่ชาร์จไหม
