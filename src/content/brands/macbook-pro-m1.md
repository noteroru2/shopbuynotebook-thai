## MacBook Pro M1 คืออะไรในมุมขาย

ชื่อ **MacBook Pro M1** บนหน้านี้เป็นตระกูลการตลาด ไม่ใช่ Exact SKU จาก Apple Support ที่ตรวจแล้วพบอย่างน้อยสองสายหลัก:

- MacBook Pro 13 นิ้ว ชิป Apple M1 (2020)
- MacBook Pro 14/16 นิ้ว ชิป Apple M1 Pro / M1 Max (2021)

ต้องอ่านชื่อชิปและขนาดจอจากเครื่องจริงก่อนประเมิน

## Chip / configuration ที่พบในแหล่งผู้ผลิต

- **CPU options:** Apple M1 8-core · M1 Pro 8/10-core · M1 Max 10-core
- **GPU options:** M1 8-core · M1 Pro 14/16-core · M1 Max 24/32-core

อย่าสรุปว่า “Pro M1 ทุกเครื่องใช้ชิปเดียวกัน”

## Memory / storage / จอ / ที่ชาร์จที่ verify แล้ว

- **Unified memory ที่พบ:** 8GB / 16GB / 32GB / 64GB (ขึ้นกับชิป)
- **SSD ที่พบ:** 256GB ถึง 8TB ตามสายเครื่อง/CTO
- **จอที่พบ:** 13.3 นิ้ว Retina · 14.2/16.2 นิ้ว Liquid Retina XDR
- **รีเฟรชที่พบในชุดข้อมูล:** 60Hz และ 120Hz (สาย XDR)
- **อะแดปเตอร์ที่พบ:** 61W · 67W · 96W USB-C
- **แบตอ้างอิง:** 58.2Wh (13 นิ้ว) / 70Wh class (14 นิ้วอ้างอิง)

## สิ่งที่ต้องตรวจบนเครื่องจริง

- ชิปว่าเป็น M1, M1 Pro หรือ M1 Max
- ขนาดจอ 13 / 14 / 16
- สภาพจอ Retina หรือ XDR รวมถึง Touch Bar ถ้าเป็นสาย 13 นิ้ว
- บอดี้ มุมเครื่อง บานพับ
- Keyboard / trackpad / พอร์ต
- Battery Health เป็นปัจจัยสภาพ ไม่ใช่เกณฑ์ราคาตายตัว
- ที่ชาร์จและความครบของอุปกรณ์

## ข้อมูลที่ควรส่งร้าน

- รูป About This Mac ที่เห็นชิป ความจุ และขนาดจอ
- รูป Battery Health / Cycle Count
- รูปเครื่องรอบด้านและจอ
- รูปอะแดปเตอร์ถ้ามี
- แจ้ง Warranty/AppleCare เฉพาะเมื่อมีหลักฐาน

## บัญชีและความเป็นส่วนตัว

สำรองข้อมูล แล้ว Sign out และปิด Find My ตามขั้นตอนของ Apple ก่อนส่งมอบ ร้านจะไม่ยืนยันการปลด Activation Lock หากยังไม่ได้ตรวจเครื่อง

## คำเตือนหลาย configuration

ส่งแค่คำว่า “MacBook Pro M1” ไม่พอสำหรับประเมิน เพราะสาย 13 นิ้วกับสาย M1 Max ต่างกันทั้งตลาดมือสองและความจุที่เป็นไปได้
