## MacBook Pro M2 คืออะไรในมุมขาย

ชื่อ **MacBook Pro M2** ครอบคลุมทั้งสาย 13 นิ้วชิป M2 และสาย 14/16 นิ้วชิป M2 Pro/Max ตามกรอบ Identify/Tech Specs ของ Apple ที่นำมา verify หน้านี้จึงเป็น MODEL_FAMILY ไม่ใช่ Exact SKU

## Chip / configuration

ตัวเลือกชิปที่พบในชุดข้อมูลที่ตรวจแล้ว:

- Apple M2 8-core CPU (สาย 13 นิ้ว)
- Apple M2 Pro 10/12-core CPU
- Apple M2 Max 12-core CPU

พร้อมตัวเลือก GPU ในตระกูล M2 / M2 Pro / M2 Max ตามสายเครื่อง

## Memory / storage / จอ / พอร์ตที่ verify แล้ว

- **Unified memory ที่พบ:** 8GB ถึง 96GB ตามชิป/CTO
- **SSD ที่พบ:** 256GB ถึง 8TB ตามสายเครื่อง/CTO
- **จอที่พบ:** 13.3 นิ้ว Liquid Retina · 14.2/16.2 นิ้ว Liquid Retina XDR
- **รีเฟรชที่พบ:** 60Hz และ 120Hz
- **พอร์ต/จุดเด่นตามสาย:** MagSafe 3 · Thunderbolt/USB-C · HDMI/SDXC ในสาย 14/16 · Touch Bar ในสาย 13 นิ้ว
- **อะแดปเตอร์ที่พบ:** 67W / 96W USB-C

- ชื่อชิปใน About This Mac

- พอร์ต MagSafe / Thunderbolt / HDMI / SD
- Battery condition เป็นปัจจัยสภาพ
- ความครบของที่ชาร์จ

## ข้อมูลที่ควรส่งร้าน

- รูป About This Mac
- รูป Battery Health
- รูปจอและตัวเครื่องรอบด้าน
- แจ้งว่าเป็น 13 / 14 / 16 นิ้ว
- รูปอะแดปเตอร์ถ้ามี
- หลักฐานประกันเฉพาะเมื่อมีจริง

## บัญชีและความเป็นส่วนตัว

สำรองข้อมูล แล้ว Sign out / ปิด Find My ตามแนวทางของ Apple ก่อนส่งมอบ อย่าอ้างสถานะ Activation Lock หากยังไม่ได้ตรวจเครื่อง

## คำเตือนหลาย configuration

ชื่อ “MacBook Pro M2” อย่างเดียวไม่พอ M2 ฐานกับ M2 Max ต่างกันชัดทั้งความจุที่เป็นไปได้และความต้องการตลาดมือสอง
