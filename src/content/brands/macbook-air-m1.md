## MacBook Air M1 ในมุมขายมือสอง

หน้านี้รองรับตระกูล **MacBook Air ชิป M1** (จอ 13.3 นิ้วตามข้อมูล Apple Support ที่ตรวจแล้ว) ไม่ใช่ Exact SKU เดี่ยว ผู้ขายที่มีเครื่องรุ่นนี้ควรยืนยันชิป ความจุ และสภาพจริงก่อนส่งประเมิน

## Chip / configuration ที่ต้องอ่านจากเครื่อง

จากข้อมูลผู้ผลิตที่ verify แล้ว ตระกูลนี้ใช้ **Apple M1 8-core CPU** และมีตัวเลือก GPU ดังนี้:

- Apple M1 7-core GPU
- Apple M1 8-core GPU

ชิปเดียวกันยังมีความจุต่างกันได้ จึงห้ามอ้างจากชื่อ “Air M1” อย่างเดียว

## Memory / storage ที่ตรวจแล้ว

Unified Memory และ SSD ฝังบอร์ด อัปเกรดภายหลังไม่ได้ ตัวเลือกที่พบในชุดข้อมูลที่ verify:

- **Memory:** 8GB / 16GB
- **Storage:** 256GB / 512GB / 1TB / 2TB

## จอและสิ่งที่ควรตรวจบนเครื่องจริง

- จอ Retina 13.3 นิ้ว: รอยขีด ร้าว จุดเสีย หรือคราบสว่างผิดปกติ
- ตัวเครื่องอลูมิเนียม: มุมบิ่น ฝาบวม รอยตก
- Keyboard / trackpad: ปุ่มค้าง หรือ trackpad ตอบสนองผิดปกติ
- พอร์ต Thunderbolt / USB 4 ทั้งสองฝั่ง
- Battery condition: ดู Battery Health และ Cycle Count เป็นปัจจัยสภาพ ไม่ใช่สูตรตัดราคาตายตัว
- ที่ชาร์จ: แจ้งว่ามีหรือไม่มีของแท้

## ข้อมูลที่ควรส่งร้าน

- รูป About This Mac ที่เห็นชิป M1 และความจุ
- รูป Battery Health / Cycle Count ถ้าเปิดดูได้
- รูปเครื่องรอบด้านและหน้าจอเปิดค้าง
- แจ้งว่าเป็น GPU 7-core หรือ 8-core หากอ่านค่าได้
- รูปที่ชาร์จถ้ามี
- แจ้ง Warranty / AppleCare เฉพาะเมื่อมีหลักฐานจริง

## บัญชีและความเป็นส่วนตัว

สำรองไฟล์สำคัญ ออกจาก iCloud/iMessage และปิด Find My ตามแนวทางของ Apple ก่อนส่งมอบ ร้านจะไม่ยืนยันสถานะ Activation Lock จากรูปอย่างเดียว

## คำเตือนหลาย configuration

ชื่อ “MacBook Air M1” ครอบคลุมหลายความจุ ราคาประเมินมือสองจึงแยกตามเครื่องจริง ไม่ใช่ค่ากลางจากชื่อรุ่นการตลาด
