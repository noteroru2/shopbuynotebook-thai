## Lenovo Legion Pro คืออะไรในมุมขาย

**Lenovo Legion Pro** บนหน้านี้เป็นซีรีส์เกมมิ่งที่รวมสาย **Pro 5 / 5i / 7 / 7i** จึงประเมินระดับ **SERIES** ไม่ใช่ Exact SKU เดี่ยว ชุดข้อเท็จจริงที่ verify มาจาก Lenovo PSREF ของตัวอย่าง **Legion Pro 5 16IRX10** และ **Legion Pro 7 16IRX8H** เท่านั้น ห้ามอ่าน GPU ของ Pro 7 แล้วสรุปว่าทุก Legion Pro ใช้การ์ดระดับนั้น

## สเปกตัวเลือกจาก Lenovo PSREF (ตัวอย่างสองสาย)

### ตัวอย่าง Legion Pro 5 16IRX10

- **CPU ที่พบ:** Intel Core i7-14650HX · i7-14700HX · i9-14900HX
- **GPU ที่พบ:** NVIDIA GeForce RTX 5050 · RTX 5060 · RTX 5070 Laptop GPU
- **RAM ที่พบ:** DDR5 · ช่อง SODIMM 2 · สูงสุดตาม PSREF 32GB
- **จอที่พบ:** 16 นิ้ว · 2560×1600 · 240Hz
- **แบตที่พบ:** 80Wh
- **อะแดปเตอร์ที่พบ:** 245W

### ตัวอย่าง Legion Pro 7 16IRX8H

- **CPU ที่พบ:** Intel Core i9-13900HX
- **GPU ที่พบ:** NVIDIA GeForce RTX 4080 · RTX 4090 Laptop GPU
- **RAM ที่พบ:** DDR5-4800 / DDR5-5600 · ช่อง SODIMM 2
- **จอที่พบ:** 16 นิ้ว · 2560×1600 · 240Hz
- **แบตที่พบ:** 80Wh / 99.9Wh
- **อะแดปเตอร์ที่พบ:** 330W

สาย AMD หรือ generation อื่นที่ไม่อยู่ใน PDF สองฉบับนี้ยังไม่ถูกยืนยันในชุดข้อมูลนี้

## สิ่งที่ต้องตรวจบนเครื่องจริง

- ว่าเป็น Pro 5 / 5i / 7 / 7i
- Machine type / รหัสรุ่นจากป้ายหรือ Vantage
- CPU/GPU/RAM/SSD จากระบบ
- สภาพพัดลม Coldfront และช่องลม
- จอมีจุดเสียหรือแสงรั่วหรือไม่
- สุขภาพแบตและความครบของที่ชาร์จหัวเหลืองวัตต์สูง

## ปัจจัยที่เกี่ยวข้องกับการประเมิน

**ข้อเท็จจริงรุ่น:** สาย Pro 5 กับ Pro 7, machine type, CPU/GPU จาก PSREF ที่ verify, ความจุ, รีเฟรชจอ, วัตต์อะแดปเตอร์

**ปัจจัยสภาพ:** พัดลม, จอ, บอดี้, แบต, ที่ชาร์จ

## รูปและข้อมูลที่ควรส่ง

- รหัสรุ่นเต็มหรือ machine type
- แคปสเปกระบบ
- รูปจอ คีย์บอร์ด ฝาบน ก้นเครื่อง
- รูปอะแดปเตอร์ถ้ามี
- แจ้งอาการความร้อนสูง เครื่องดับ หรือพัดลมดัง

## คำเตือนหลายสายย่อย

ชื่อ “Legion Pro” อย่างเดียวไม่พอสำหรับประเมิน อย่าใช้สเปก RTX 4080/4090 ของ Pro 7 เป็นตัวแทน Pro 5 และอย่าใช้สเปก RTX 50-series ของตัวอย่าง 16IRX10 เป็นตัวแทนทุกปี
