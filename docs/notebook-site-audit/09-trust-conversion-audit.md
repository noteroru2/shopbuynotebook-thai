# Trust and Conversion Audit

## จุดแข็ง

- CTA LINE/โทรชัด
- มี process, pricing factors, FAQ, about, contact, privacy
- ระบุว่าราคาสุดท้ายขึ้นกับการตรวจสภาพ
- มี storefront/location evidence ใน content และ schema
- รองรับลูกค้าทั่วไปและองค์กรโดยแยกหน้า

## Trust gaps

- location wording บางหน้ากล่าวเชิง availability มากเกินหลักฐาน
- claims เช่น “ไว”, “ราคาดี”, “ผู้เชี่ยวชาญ” ควรมีหลักฐานหรือปรับเป็นภาษากระบวนการ
- review provenance/วันที่/แหล่งที่มาต้องสม่ำเสมอ
- ควรอธิบายการจัดส่ง ความเสี่ยง ค่าขนส่ง การคืนสินค้าเมื่อไม่ตกลง และการชำระเงินให้ครบ
- ต้องแยก “ประเมินเบื้องต้นจากรูป” กับ “ราคาสุดท้ายหลังตรวจ” ทุก CTA funnel

## Conversion priorities

1. CTA หลักเดียว: ส่งรูป + รุ่น + สเปก + อาการ
2. แสดง required inputs ก่อนเปิด LINE
3. แสดงเงื่อนไขจังหวัดอื่นก่อนนัด
4. ใส่ proof ใกล้ CTA: หน้าร้านจริง, process, payment condition
5. วัด click-to-LINE/call แยกตาม URL โดยไม่เปิดเผยข้อมูลส่วนบุคคล

Primary commercial pages คือ homepage, used notebook, pricing, company bulk และ high-value brand/condition hubs
