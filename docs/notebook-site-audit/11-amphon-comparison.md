# Comparison with amphon.co.th

ตรวจหน้า homepage ของ `https://amphon.co.th/` เมื่อ 29 กรกฎาคม 2026

## สิ่งที่โครงสร้างใกล้เคียงแล้ว

- ส่งรูปประเมินผ่าน LINE
- แสดงขั้นตอนขาย
- มี service/location/blog/trust hubs
- มีหน้าร้านจริงอุบลราชธานี
- มี CTA ซ้ำในจุดสำคัญ
- มี FAQ และ pricing-condition messaging

## สิ่งที่ควรนำแนวทางมาใช้

1. แยกสถานะพื้นที่ชัด: หน้าร้านหลัก / นัดรับตามตาราง / จัดส่ง
2. ขั้นตอน 4 ขั้นพร้อมย้ำว่าราคาจากรูปเป็นเบื้องต้นและราคาสุดท้ายหลังตรวจ
3. storefront proof ใกล้ข้อมูลบริษัทและ CTA
4. navigation แบบ hub-and-spoke ที่ผู้ใช้เข้าใจทันที
5. required-input checklist แยกตามประเภทสินค้า
6. trust language ที่อิงสิ่งตรวจสอบได้แทน superlative

หลักฐานหน้า amphon.co.th ระบุหน้าร้านหลักแห่งเดียวที่อุบลราชธานี และจังหวัดอื่นต้องประเมิน/ยืนยันก่อนนัด จึงเป็นรูปแบบถ้อยคำที่เหมาะกับข้อเท็จจริงของเว็บนี้

## สิ่งที่ห้ามนำมาใช้

- breadth ด้าน iPhone, iPad, กล้อง, RAM แยกชิ้น, desktop, gaming PC, workstation, server/network/UPS
- homepage intent “สินค้าไอทีมือสองทั่วประเทศ”
- จำนวน landing page ข้ามหมวด
- การคัดลอกข้อความ เนื้อหา รูป หรือ schema โดยตรง

## Positioning ที่ควรต่าง

ร้านรับซื้อโน๊ตบุ๊ค.com ควรเป็น “Notebook specialist”: ประเมินตามรุ่น/สเปก/แบต/จอ/บอดี้/อาการ พร้อมความรู้เชิงลึกตาม brand, series, model และ failure mode ไม่ใช่ general IT buyer
