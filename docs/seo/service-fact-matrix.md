# Service Fact Matrix

เอกสารนี้เป็น Source of Truth สำหรับข้อความบริการของร้านรับซื้อโน๊ตบุ๊ค.com

## หน้าร้านจริง

- หน้าร้านจริงอยู่จังหวัดอุบลราชธานี
- ชื่อหน้าร้าน: ร้านอำพล เทรดดิ้ง
- ที่อยู่ โทรศัพท์ เวลาเปิด และ Google Maps ต้องใช้ค่าจาก `src/config/site.ts`
- ห้ามสร้างที่อยู่หรือสาขาใหม่

## จังหวัดอื่น

- ลูกค้าส่งรูป รุ่น สเปก อาการ อุปกรณ์ และจังหวัดเพื่อประเมินเบื้องต้นได้
- การนัดรับขึ้นอยู่กับพื้นที่ ตารางงาน และการยืนยันจากทีมงาน
- บางกรณีนัดตามจุดที่ตกลงร่วมกัน
- ลูกค้าสามารถสอบถามขั้นตอนจัดส่งเครื่องมาตรวจได้
- ราคาสุดท้ายยืนยันหลังตรวจเครื่องจริง
- ลูกค้าไม่จำเป็นต้องตกลงขายจากราคาเบื้องต้น

## ข้อความที่ห้ามใช้

- มีสาขา สำนักงาน หรือทีมงานประจำจังหวัดอื่น
- รับถึงบ้านได้ทุกจังหวัด หรือนัดรับได้ทันที
- จุดนัดรับประจำหรือยอดฮิตโดยไม่มีหลักฐาน
- ราคาจากรูปเป็นราคาสุดท้าย
- ชำระเงินก่อนตรวจเครื่อง
- ราคาสูงที่สุด

## ขอบเขตสินค้า

โดเมนนี้เน้นโน๊ตบุ๊ค, Gaming Notebook, Ultrabook, Business/Workstation Notebook, MacBook ตามโครงสร้างเดิม, เครื่องเก่า, เครื่องเสียบางอาการ และเครื่ององค์กร/หลายเครื่อง อุปกรณ์เสริมกล่าวได้เมื่อเป็นส่วนหนึ่งของการประเมินเครื่อง แต่ไม่ทำเป็นบริการรับซื้อสินค้าไอทีทั่วไป
